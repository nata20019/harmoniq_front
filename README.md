# harmoniq-front

Це фронтенд-частина додатка, побудована на React. Проєкт використовує CSS
Modules для ізольованої стилізації компонентів.

## 🔗 Посилання

- **Demo:** [Посилання на Vercel/Netlify]
- **Backend API:** [Посилання на ваш репозиторій з бекендом]

## 🛠 Технологічний стек

- **React** (Vite)
- **CSS Modules** — стилізація
- **Axios** — HTTP-запити до API
- **React Router Dom** — навігація
- **React Hook Form / Joi** — робота з формами та валідація

## ⚙️ Налаштування середовища

Для роботи фронтенду потрібно створити файл `.env` у корені проєкту:

REACT_APP_API_URL=http://localhost:3000/api
